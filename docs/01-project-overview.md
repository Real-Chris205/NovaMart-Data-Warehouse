# NovaMart Data Warehouse

## Project Overview

NovaMart is an end-to-end Data Engineering project focused on designing and implementing a relational data warehouse from an operational e-commerce database.

The project covers the complete data engineering lifecycle, including OLTP database design, data quality assessment, data remediation, dimensional modelling, ETL implementation, and warehouse validation.

## Project Goal

To transform operational e-commerce data into a structured dimensional data warehouse that supports reliable analytical queries and preserves historical dimension records.

## Technology Stack

- PostgreSQL
- SQL
- pgAdmin 4
- Dimensional Modelling
- Star Schema
- Slowly Changing Dimension Type 2 (SCD Type 2)
